# Android Review Skill 技术说明书

## 概述

本技术说明书详细描述了 Android Review Skill 的系统架构、设计理念、核心组件和实现细节。该工具是一个专业的 Android/Kotlin 代码审查平台，支持静态规则扫描、LLM语义分析和自动化报告生成。

### 架构设计原则

1. **模块化设计**：各组件职责单一，便于维护和扩展
2. **向后兼容**：支持新旧系统平滑过渡
3. **高性能**：支持并行处理和缓存优化
4. **可配置性**：支持运行时动态配置
5. **可扩展性**：支持插件化和自定义规则

## 核心组件详解

### 1. 规则引擎（Rule Engine）

#### 1.1 设计目标
- 统一管理所有规则，消除分散的规则文件
- 支持动态注册/注销规则
- 提供标准化的规则接口
- 支持并行执行和缓存优化

#### 1.2 主要组件

##### 1.2.1 规则接口（Rule Interface）
```python
class Rule(ABC):
    """规则抽象基类"""
    
    @property
    @abstractmethod
    def metadata(self) -> RuleMetadata:
        """获取规则元数据"""
        pass
    
    @abstractmethod
    def check(self, context: 'RuleContext') -> List[Finding]:
        """
        检查代码，返回发现的问题
        
        Args:
            context: 规则上下文，包含代码、文件信息等
            
        Returns:
            发现的问题列表
        """
        pass
```

##### 1.2.2 规则元数据（RuleMetadata）
```python
@dataclass
```

##### 执行模式

- **内存缓存**：LRU策略，限制最大缓存条目

### 3. 审查运行器（Review Runner）

#### 3.1 核心流程
```
1. 初始化配置
2. 获取Git差异
3. 过滤文件（根据配置）
4. 初始化规则引擎
5. 对每个文件执行规则
6. 聚合结果，计算分数
7. 生成报告
8. 输出结果
```

#### 3.2 混合模式支持
```python
class ReviewRunner:
    """审查运行器，支持新旧引擎"""
    
    def __init__(self, config: Optional[Dict[str, Any]] = None):
        self.config = config or {}
        self.registry = RuleRegistry()
        self.engine = RuleEngine(self.registry)
        
    def review_diff(self, diff: str) -> List[Dict[str, Any]]:
        """审查Git diff"""
        # 解析diff，对每个文件执行审查
        files = parse_git_diff(diff)
        results = []
        
        for file_info in files:
            context = RuleContext(
                code=file_info['content'],
                file_path=file_info['path'],
                language="kotlin"
            )
            
            findings, stats = self.engine.execute_all(context)
            score = self._calculate_score(findings)
            
            results.append({
                "file": file_info['path'],
                "findings": findings,
                "score": score,
                "stats": stats
            })
        
        return results
```

### 3. 规则评分系统

#### 3.1 分数计算算法
```
初始分数 = 100
for 每个发现的问题:
    if 严重级别 == INFO: 扣分 = 0
    elif 严重级别 == MINOR: 扣分 = 5
    elif 严重级别 == MAJOR: 扣分 = 10
    elif 严重级别 == CRITICAL: 扣分 = 20
    elif 严重级别 == BLOCKER: 扣分 = 100
    
    最终扣分 = 扣分 * 规则权重
    当前分数 -= 最终扣分

最终分数 = max(0, min(100, 当前分数))
```

#### 3.2 阻塞条件
1. **分数阈值**：低于配置的最小分数阈值（默认70分）
2. **关键问题**：存在严重级别为CRITICAL或BLOCKER的问题
3. **自定义规则**：特定规则可以标记为阻塞性

## 文件处理系统

### 1. Git差异处理

#### 1.1 差异获取策略
```python
def get_git_diff():
    """获取Git差异"""
    diff_commands = [
        ["git", "diff", "original/develop...HEAD"],  # PR审查
        ["git", "diff", "HEAD~1", "HEAD"],           # 最新提交
        ["git", "diff", "--staged"]                  # 暂存区
    ]
    
    for cmd in diff_commands:
        result = subprocess.run(cmd, capture_output=True, text=True)
        if result.stdout.strip():
            return result.stdout
    
    return ""  # 无变更
```

#### 1.2 差异解析
- 解析 `diff --git` 行，提取文件路径
- 区分新增、修改、删除的文件
- 提取变更的代码内容
- 按文件分组处理

### 2. 文件过滤系统

#### 2.1 过滤策略
1. **扩展名过滤**：只扫描配置的扩展名（.kt, .kts）
2. **目录过滤**：只扫描配置的目录
3. **模式排除**：使用glob模式排除特定文件/目录

#### 2.2 过滤实现
```python
class ReviewConfig:
    def should_scan_file(self, file_path: str) -> bool:
        """判断是否应该扫描指定文件"""
        # 检查文件扩展名
        ext = Path(file_path).suffix.lower()
        if ext not in self.get_file_extensions():
            return False
        
        # 检查是否在扫描目录中
        in_scan_dir = any(file_path.startswith(dir) for dir in self.get_scan_directories())
        if not in_scan_dir:
            return False
        
        # 检查是否匹配排除模式
        for pattern in self.get_exclude_patterns():
            if fnmatch.fnmatch(file_path, pattern):
                return False
        
        return True
```

## 性能优化策略

### 1. 并行处理优化

#### 1.1 线程池管理
```python
class ParallelRuleExecutor:
    """并行规则执行器"""
    
    def __init__(self, max_workers: int = None):
        self.max_workers = max_workers or os.cpu_count()
        self.executor = ThreadPoolExecutor(max_workers=self.max_workers)
    
    def execute_rules(self, rules: List[Rule], context: RuleContext):
        """并行执行规则"""
        futures = {}
        for rule in rules:
            future = self.executor.submit(rule.check, context)
            futures[future] = rule
        
        # 收集结果
        all_findings = []
        for future in as_completed(futures):
            findings = future.result()
            all_findings.extend(findings)
        
        return all_findings
```

#### 1.2 规则分类调度
- **CPU密集型规则**：正则匹配、AST分析等
- **I/O密集型规则**：文件读取、网络请求等
- **快速规则**：简单字符串匹配等

```python
class YamlRuleLoader(RuleLoader):
    """YAML规则加载器"""
    
    def load_rules(self, yaml_file: str) -> List[Rule]:
        with open(yaml_file, 'r') as f:
            config = yaml.safe_load(f)
            return self._parse_rules(config['rules'])


class PythonModuleRuleLoader(RuleLoader):
    """Python模块规则加载器"""
    
    def load_rules(self, module_path: str) -> List[Rule]:
        module = importlib.import_module(module_path)
        rules = []
        for attr_name in dir(module):
            attr = getattr(module, attr_name)
            if isinstance(attr, Rule):
                rules.append(attr)
        return rules
```
